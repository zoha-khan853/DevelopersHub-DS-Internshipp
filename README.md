# Task 1: Exploring and Visualizing the Iris Dataset

## Objective
Understand how to read, summarize and visualize a dataset.

## Dataset
Iris Dataset loaded directly from seaborn library.

## Approach
- Loaded dataset using pandas and seaborn
- Explored shape, columns and basic statistics
- Created scatter plot, histogram and box plot

## Results and Insights
- Dataset has 150 rows and 5 columns
- No missing values found
- Setosa species is clearly separable from others
- Petal length is the most distinguishing feature
